04 / FAQ

Что обычно спрашивают

Нет ответа — напишите в Telegram.

// 01Что такое «сквозная аналитика»?
Связь данных: реклама → сайт → лид → CRM → сделка → выручка. Видите не «100 кликов», а «100 кликов → 12 лидов → 3 сделки → 480 000 ₽».
// 02Чем server-side лучше обычного?
Браузерные блокировщики режут 20–40% событий. Server-side даёт реальную картину. На больших объёмах — миллионы рублей выручки.
// 03С какими CRM работаете?
amoCRM, Bitrix24, HubSpot, Salesforce. С другими — через API. Делали кастомные интеграции с 1С и SAP.
// 04Можно только дашборд?
Если источники настроены — да. Иначе построим всю инфраструктуру, иначе дашборды покажут «фантомы».
// 05Кто поддерживает после запуска?
Передаём документацию, обучаем команду. Если нет аналитика — берём на сопровождение от 15 000 ₽/мес.
