05 / FAQ

Что обычно спрашивают

Нет ответа — напишите в Telegram.

// 01Делаете native или кроссплатформу?
Зависит от задачи. Для большинства продуктов — React Native: единая кодовая база, в 2 раза дешевле, скорость на уровне native. Когда нужна максимальная производительность — Swift / Kotlin.
// 02Поможете опубликовать в App Store?
Да. Берём на себя всю бюрократию: подготовку метаданных, скриншоты, прохождение модерации. Учётка в Apple Developer оформляется на ваше юр-лицо.
// 03Что с обновлениями iOS/Android?
Apple и Google обновляют ОС раз в год — приложения нужно адаптировать. Включаем в пакет поддержки. Без поддержки — отдельно по факту.
// 04Можно ли передать существующее приложение?
Можно. Делаем аудит кода, оцениваем долг, предлагаем план — поддержка, рефакторинг или переписывание.
