06 / FAQ

Что обычно спрашивают

Нет ответа — напишите в Telegram.

// 01Куда уйдут наши данные?
По умолчанию — никуда. Запросы идут через API провайдера (OpenAI/Anthropic), они не используют их для обучения. Если данные чувствительные — разворачиваем локальную Llama на ваших серверах, наружу не уходит ничего.
// 02Сколько стоит API в месяц?
Зависит от объёма. Для типичного чат-бота с 1000 запросов в день — 3–8 тысяч рублей в месяц. Считаем точно после брифа.
// 03А если модель ошибётся?
Не используем AI там, где ошибка фатальна (например, медицина). Везде где можно — внедряем human-in-the-loop: AI готовит ответ, человек подтверждает.
// 04Заменит ли AI наших сотрудников?
Часто нет — а усилит. Сотрудник + AI делает работу в 5 раз быстрее. Иногда — да, рутина уходит. Решаем вместе на брифе.
